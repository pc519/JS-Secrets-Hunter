# 🔑 JS Secrets & API Keys Hunter

An automated Python security auditing tool that crawls web pages, extracts linked JavaScript (.js) files, and scans them using pattern matching to detect accidentally exposed API keys, tokens, and credentials, generating a clean HTML report.

### ✨ Features
- Automated JS Extraction: Finds and parses all external JavaScript files referenced on a webpage.
- Secret Detection: Scans for exposed Google API keys, AWS keys, Stripe live keys, Firebase URLs, JWT tokens, and hardcoded passwords.
- Safe Masking & Reporting: Masks sensitive values in the generated HTML report for safe sharing with clients.

# 🔑 صائد الأسرار ومفاتيح API في ملفات JavaScript

أداة بايثون مؤتمتة لفحص المواقع الإلكترونية واستخراج جميع ملفات JavaScript المرتبطة بها، والبحث بداخلها عن مفاتيح API أو كلمات المرور أو الرموز السرية المنسية والمكشوفة للعامة، مع توليد تقرير HTML احترافي ومنظم.
